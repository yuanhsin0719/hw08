## 3. 個人問題回答

### 問題一：測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？
- **費用計算原因**：整理後的桌遊串列為 `['amy', 'ben', 'amy', 'cora']`，雖然有 4 筆資料，但其中 `amy` 重複出現了兩次（原始名單中的 `" Amy"` 與 `"amy"` 統一轉小寫去空白後為同一人）。依據規則，同一個人在同一場活動重複報名只算一位參加者、只收一次費，實際獨立參加者只有 `amy`、`ben`、`cora` 共 3 人，因此費用應以 `3 × 120 = 360` 元計算。
- **容器特性比較**：
  - **直接拆成 `list`**：**保留了**原始報名出現的先後順序，以及重複報名的次數紀錄（能看出誰重複報名）；但**失去了**自動過濾重複項目的功能，也無法直接進行交集或差集等集合比對。
  - **再轉成 `set`**：**保留了**不重複的唯一參加者名單，並獲得快速做交集、聯集與差集運算的能力；但**失去了**原本的報名順序以及每個人重複報名的次數紀錄。

### 問題二：測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。
- **集合關係說明**：在測試三中，桌遊集合 $A = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，電影集合 $B = \{\text{'amy'}, \text{'ben'}, \text{'cora'}\}$，兩個集合的元素完全相同（$A = B$）。因此兩者的聯集 $A \cup B$ 只有 3 個元素，代表**總不重複人數為 3 人**；而兩者的交集 $A \cap B$ 也是這 3 人（各自差集 $A - B$ 與 $B - A$ 皆為空集合 $\emptyset$），表示這 3 位參加者**兩場活動都有參加**。
- **算式說明**：
  - **報名人次**：計算的是兩場活動各自去重後的人數總和，即 $|A| + |B| = 3 + 3 = 6$ 人次（因為 3 個人各參加了 2 場活動，所以累計為 6 人次）。
  - **總應收費用**：兩場活動依各自參加人數分別計費再加總，算式為 $(|A| \times 120) + (|B| \times 80) = (3 \times 120) + (3 \times 80) = 360 + 240 = 600$ 元。
